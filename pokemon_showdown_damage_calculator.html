Deploying to GitHub Pages

This app is entirely self-contained in a single file with zero external runtime server dependencies!

  1. Create a new repository on GitHub (e.g., pokemon-damage-calc).
  2. Create a file named index.html in the root directory.
  3. Paste the complete code of this file into index.html.
  4. Go to Settings -> Pages in your GitHub repository.
  5. Set source to Main branch / (root) and click Save!
